📱 Telegram Setup Guide

  1. Message @BotFather on Telegram → type /newbot → follow steps → copy the token
  2. Message @userinfobot on Telegram → it replies with your chat_id
  3. Add both to Railway Variables: TELEGRAM_BOT_TOKEN and TELEGRAM_CHAT_ID
  4. Click Test Telegram above to verify
